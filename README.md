# 📊 Dashboard de Vendas do Xbox – Excel

Este repositório contém um **Dashboard de Vendas do Xbox desenvolvido no Microsoft Excel**, utilizando **Tabelas Dinâmicas**, **Gráficos Dinâmicos** e **segmentações de dados** para análise interativa das informações.

## 📁 Arquivo do Projeto

* `Dashboard de Vendas do Xbox com Excel.xlsx`

## 🎯 Objetivo do Dashboard

Fornecer uma visão clara e interativa das vendas do Xbox, permitindo:

* Acompanhamento de desempenho de vendas
* Análise por período, região e produto
* Identificação de tendências e comparações

### 🔹 Base de Dados

A planilha contém uma base de dados estruturada com informações como:

* Data da venda
* Produto / Modelo do Xbox
* Região / País
* Quantidade vendida
* Valor de venda
* Receita total

*(Os nomes das colunas podem variar conforme a aba de dados)*

### 🔹 Tabelas Dinâmicas

As **Tabelas Dinâmicas** são utilizadas para:

* Consolidação dos dados
* Cálculo de totais e métricas
* Suporte aos gráficos do dashboard

Principais análises:

* Vendas totais por período
* Receita por região
* Quantidade vendida por produto
* Comparativos entre categorias

### 🔹 Dashboard

O dashboard foi construído a partir das tabelas dinâmicas e inclui:

* Gráficos de barras
* Gráficos de colunas
* Gráficos de linhas
* Indicadores de desempenho

### 🔹 Segmentações de Dados

Para tornar a análise interativa, o dashboard conta com **segmentações de dados**, permitindo filtros por:

* Ano / Mês
* Região
* Produto
* Categoria

## 🛠️ Ferramentas Utilizadas

* Microsoft Excel
* Tabelas Dinâmicas
* Gráficos Dinâmicos
* Segmentação de Dados

## 🚀 Como Utilizar

1. Faça o download do arquivo Excel
2. Abra no Microsoft Excel (versão 2016 ou superior recomendada)
3. Utilize as segmentações para filtrar os dados
4. Analise os gráficos e indicadores do dashboard

## 📌 Observações

* O dashboard é totalmente dinâmico e responde aos filtros aplicados
* Alterações na base de dados atualizam automaticamente as análises
